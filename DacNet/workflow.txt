APEX-Net / DACNet workflow summary
==================================

Lung ROI script
---------------
Script: scripts/lung_roi.py

This is the new, separate lung-segmentation workflow. It trains a custom U-Net
on the JSRT X-rays and masks, then uses that checkpoint to create a lung mask
for every NIH image. Post-processing keeps up to two largest connected
components, fills their convex hulls, and dilates the result.

Current defaults are configured in DEFAULT_CONFIG in scripts/lung_roi.py:
  JSRT images: C:\JSRT\jsrt\cxr
  JSRT masks:  C:\JSRT\jsrt\masks
  NIH images:  C:\NIH_data
  device:      cuda
  U-Net weights: models\lung_unet.pth

From the DacNet project directory:
  python scripts\lung_roi.py train
  python scripts\lung_roi.py generate

The generated NIH masks go under C:\NIH_data\lung_masks and keep the original
image dimensions and relative folders. DACNet and FZLPR-DACNet do not consume
these masks; APEX-Net uses them during training.

Classification models
---------------------
Basic DACNet: scripts/dacnet.py

This trains a DenseNet-121 classifier for the 14 NIH ChestX-ray14 findings.
It uses a focal loss to emphasize harder examples, which is intended to help
with class imbalance. Its best checkpoint is saved as:
  models\<Weights & Biases run ID>\best_model_<timestamp>.pth
The latest completed focal-loss checkpoint currently in the repository is:
  models\yyc9g0js\best_model_20260802-061232.pth

FZLPR-DACNet: scripts/dacnet_fzlpr.py

This is the FZLPR version of the DenseNet-121, 14-label classifier. It uses
FZLPR loss (with configurable temperature tau) and supports test-time
augmentation (horizontal flip and zoom) when evaluating. Its best checkpoint
is saved in the same run-specific location:
  models\<Weights & Biases run ID>\best_model_<timestamp>.pth

These classification checkpoints are independent of the U-Net checkpoint.
Training the U-Net neither loads nor overwrites the DACNet weights.

Prior maps
----------
Script: scripts/generate_prior_maps.py

This reads NIH bounding-box annotations from BBox_List_2017.csv and creates
one disease-specific spatial prior map per finding as a .npy file. Annotated
findings are built from the bounding boxes; unannotated findings get an
all-ones map. By default maps are saved under:
  DacNet\prior_maps\

Example:
  python scripts\generate_prior_maps.py --data_dir C:\NIH_data

The prior-map generator is also a separate preprocessing step; generating the
files alone does not apply them to DACNet or FZLPR-DACNet.

APEX-Net with APAM
------------------
Script: scripts/train_apexnet.py

APEX-Net starts with a pretrained DenseNet-121 and trains it with two spatial
cues: the lung ROI mask identifies where the lungs are, and each disease prior
map provides a rough class-specific location bias. APAM pools feature
descriptors from the full image and the masked region, then learns channel
weights to combine them. Each disease gets separate lung-mask and prior-map
attention branches before its classifier. This guides existing image features
toward relevant anatomy without replacing the image or serving as a disease
label. Priors are dataset-level maps, not per-image lesion annotations;
unannotated diseases have all-ones priors and therefore get no spatial
filtering from that branch.

Train from the DacNet project directory after generating the masks and priors:
  python scripts\train_apexnet.py --data_dir C:\NIH_data

The trainer applies matching crops/flips to each image and its masks/priors.
Its APEX-Net checkpoint is separate from DACNet and U-Net checkpoints.

Previously available classifier checkpoints are not moved by these workflows.
Check the models directory for the actual run ID and timestamp of each saved
classification checkpoint.
